SteadyStreak AWS Security Implementation

WAF and IP Throttling Architecture

1. AWS WAFv2 Implementation

The application uses AWS WAFv2 (Web Application Firewall) in regional mode to protect the API Gateway endpoints. The WAF is configured with the following key components:

WebACL Configuration

WebACL:
  Type: AWS::WAFv2::WebACL
  Properties:
    Name: !Sub "${AWS::StackName}-waf"
    Scope: REGIONAL
    DefaultAction: { Allow: {} }
    VisibilityConfig:
      CloudWatchMetricsEnabled: true
      MetricName: waf-api
      SampledRequestsEnabled: true

2. Rate Limiting Rules

The WAF implements two main rate limiting rules with different priorities:

2.1 Global IP-based Rate Limit

  • Rule Name: PerIpGlobalLimit
  • Priority: 1 (evaluated first)
  • Limit: Configurable via WafPerIpLimit parameter (default: 1000 requests per 5 minutes per IP)
  • Scope: Applies to all requests
Rules:
  - Name: PerIpGlobalLimit
    Priority: 1
    Statement:
      RateBasedStatement:
        Limit: !Ref WafPerIpLimit
        AggregateKeyType: IP
    Action: { Block: {} }

2.2 Protected Endpoint Rate Limit

  • Rule Name: PerIpProtectedTight
  • Priority: 2 (evaluated second)
  • Limit: 300 requests per 5 minutes per IP
  • Scope: Only applies to POST requests to the "/protected" endpoint 
- Name: PerIpProtectedTight
  Priority: 2
  Statement:
    RateBasedStatement:
      Limit: 300
      AggregateKeyType: IP
      ScopeDownStatement:
        AndStatement:
          Statements:
            - ByteMatchStatement:
                FieldToMatch: { UriPath: {} }
                PositionalConstraint: EXACTLY
                SearchString: "/protected"
                TextTransformations: [{ Priority: 0, Type: NONE }]
            - ByteMatchStatement:
                FieldToMatch: { Method: {} }
                PositionalConstraint: EXACTLY
                SearchString: "POST"
                TextTransformations: [{ Priority: 0, Type: NONE }]

3. WAF Association with API Gateway

The WAF is associated with the API Gateway stage to protect all incoming requests: 

WebACLAssociation:
  Type: AWS::WAFv2::WebACLAssociation
  Properties:
    ResourceArn: !Sub "arn:aws:apigateway:${AWS::Region}::/restapis/${RestApi}/stages/${StageName}"
    WebACLArn: !GetAtt WebACL.Arn

4. Configuration and Deployment

The WAF configuration is deployed using AWS SAM (Serverless Application Model) with the following key parameters:

  • WafPerIpLimit: Configurable parameter for the global rate limit (default: 1000)
  • StageName: The API Gateway stage name (e.g., "prod")

Example deployment configuration from samconfig.toml:

parameter_overrides = "WafPerIpLimit=\"300\" StageName=\"prod\""

5. Monitoring and Visibility

The WAF is configured with CloudWatch metrics and request sampling for monitoring:

  • CloudWatch Metrics enabled for all rules
  • Sampled request logging enabled
  • Custom metric names for each rule for easy identification

Key Security Benefits

  • Protection against DDoS attacks through rate limiting
  • Granular control over different endpoints with custom limits
  • Real-time monitoring and logging capabilities
  • Infrastructure-as-Code approach using AWS SAM
  • Configurable parameters for different environments

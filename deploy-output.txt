# # SteadyStreak API
# This API provides endpoints for nonce generation, app registration, and protected resource access using App Attest

# # Endpoints
# - **Nonce Generation**: `GET /nonce?purpose=request` - Generates a nonce for the specified purpose.
# - **App Registration**: `POST /register` - Registers an app with the provided App Attest assertion and nonce.
# - **Protected Resource Access**: `POST /protected` - Accesses a protected resource using App Attest assertion and nonce.
# # Usage
# 1. Deploy the API using AWS SAM.
# 2. Use the provided API base URL to interact with the endpoints.  
# 3. Generate a nonce for a specific purpose using the `/nonce` endpoint.   
# 4. Register an app by providing the App Attest assertion and nonce using the `/register` endpoint.
# 5. Access a protected resource using the App Attest assertion and nonce in the `/protected` endpoint.
# # Security    
# The API uses AWS WAF to enforce per-IP rate limits and protect against abuse. It also employs a Lambda Authorizer to validate App Attest assertions and nonces before granting access to protected resources.
